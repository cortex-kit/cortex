# 99 - Inbox — les captures non triées

Ce qui est capté vite et n'a pas encore trouvé sa place.

**Ce dossier doit se vider, pas grossir.** Une inbox qui accumule n'est pas un problème de discipline : c'est le signe qu'on ne sait plus où ranger, donc que l'ontologie a besoin d'être revue. Six mois de captures non triées valent un examen des domaines, pas une séance de rangement.

Deux issues pour une capture : elle devient une note à sa place, ou elle est supprimée. Rester ici n'est pas une troisième issue.
