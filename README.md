# Cortex

Un second cerveau installé chez vous, en français, par une chaîne de maillons guidés.

## Trois gestes

1. Installer Claude Code, puis dans un terminal :
   `claude plugin marketplace add cortex-kit/cortex && claude plugin install cortex@cortex-kit`
2. Ouvrir Claude Code et écrire : **installe mon second cerveau**
3. À la fin de chaque séance, écrire : **clôture**

Sous Windows natif, les commandes que lance l'assistant ne sont pas confinées à votre second cerveau : seules les règles de lecture et d'édition protègent vos dossiers de travail. Rien ne bloque l'installation, mais pour un poste qui porte des données sensibles, utilisez Claude Code dans WSL2, le sous-système Linux de Windows, où ce confinement s'applique.

La notice pas à pas : [`notice/LISEZ-MOI.html`](notice/LISEZ-MOI.html). Les outils du poste : [`outils/OUTILS.md`](outils/OUTILS.md).
