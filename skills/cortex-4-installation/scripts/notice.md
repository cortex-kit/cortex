# Votre second cerveau

Un second cerveau est un dossier de notes structurées que Claude Code lit,
remplit et entretient pour vous. Chaque projet, chaque personne, chaque
décision y trouve une place. Vous posez des questions en langage ordinaire,
l'outil retrouve et relie.

Tout reste sur votre ordinateur. Vos documents ne sont pas copiés : le second
cerveau pointe vers eux. Votre messagerie n'est lue que si vous le demandez, et
seulement les en-têtes.

## Les trois gestes

Tout le parcours tient en trois phrases.

1. **Installer.** Installez Claude Code, puis dans un terminal collez la ligne
   d'installation du paquet, donnée dans le fichier README du paquet. Sans
   terminal, le zip de repli se déplie dans le dossier des savoir-faire de
   Claude Code, voir « Sans terminal » plus bas.
2. **Démarrer.** Ouvrez Claude Code et écrivez : **« installe mon second
   cerveau »**. La première étape commence et vous guide.
3. **Alimenter.** À la fin de chaque séance de travail, écrivez :
   **« clôture »**. C'est ce geste, répété, qui fait d'un dossier de notes une
   mémoire.

Entre deux étapes, cette page vous dit où vous en êtes et quelle phrase dire
pour continuer. Elle ne lance rien à votre place : vous décidez d'enchaîner.

## Les neuf étapes, en langage ordinaire

Elles se suivent dans l'ordre. Chacune demande votre accord avant d'agir et
s'arrête si quelque chose manque.

- **0. Poste.** Votre ordinateur reçoit les quelques outils nécessaires : un
  lecteur de notes, un moteur de conversion de documents, l'outil de sauvegarde
  et son compagnon en ligne, un transcripteur audio. Rien ne s'installe sans
  votre accord, outil par outil. Votre messagerie est reconnue à partir de
  votre adresse de travail, et la façon de la brancher vous est proposée. Puis
  cette page s'ouvre.
- **1. Cadrage.** Une dizaine de questions : installez-vous l'outil pour vous
  ou pour quelqu'un d'autre, êtes-vous salarié, dirigeant, ou une société de
  plusieurs personnes, où sont vos dossiers de travail, ce que l'outil peut
  regarder et ce qu'il n'ouvrira pas.
- **2. Inventaire.** L'outil compte vos dossiers et vos fichiers, repère vos
  bases et vos dépôts, sans rien lire en profondeur. Si vous l'avez autorisé,
  il regarde aussi qui vous écrit le plus, par en-têtes seulement.
- **3. Ontologie.** Vos grandes familles d'activité. L'outil compare ce que
  vous avez dit à ce qu'il a vu, pose une question par écart, et vous
  confirmez la carte.
- **4. Installation.** Le second cerveau est créé, vide et sain. Cette étape ne
  laisse pas de fichier de suivi : son résultat est le dossier lui-même, et sa
  preuve un contrôle de santé qui sort sans erreur.
- **5. Remplissage.** Vos projets réels entrent, sous forme de fiches qui
  pointent vers vos vrais fichiers. Si vous n'avez aucune base de projets, les
  quelques documents qui structurent votre travail sont copiés un par un, avec
  votre accord à chaque fois.
- **6. Agents métier.** Des assistants sur mesure, si l'usage le justifie.
  Souvent la réponse honnête est « pas encore » : ils se méritent par l'usage.
- **7. Passation.** Une fiche de reprise à froid, pour vous dans six mois, et
  deux rendez-vous de bilan, une semaine puis un mois après.
- **8. Fédération.** Pour une société : plusieurs seconds cerveaux reliés à un
  commun, généré et jamais édité à la main. Pour une personne seule, cette
  étape est sans objet et la page le dit.

Comptez une dizaine de minutes par étape, hors temps de réflexion sur vos
réponses. Vous pouvez vous arrêter entre deux étapes et reprendre plus tard :
la page retrouve où vous en étiez.

## Suivre l'avancée

Le haut de cette page montre l'étape en cours et la phrase à dire pour la
lancer. En dessous, les étapes à venir, puis les étapes faites, repliées.

Cette page se régénère à la fin de chaque étape, dans le dossier de travail
`_cortex/`, fichier `notice.html`. Si vous l'avez fermée, demandez à Claude
Code **« où en est mon installation ? »** et elle se rouvre à jour.

## Sans terminal

Le paquet existe aussi en zip. Il se déplie en dossiers frères, à déposer dans
le dossier des savoir-faire de Claude Code : `~/.claude/skills/` sur Mac et
Linux, `%USERPROFILE%\.claude\skills\` sur Windows. Si un dossier du même
nom existe déjà chez vous, ne remplacez rien : gardez le vôtre et signalez-le
dans Claude Code à la première séance.

Sur Windows, Python doit être présent. L'étape 0 vous le dit et vous donne la
commande si ce n'est pas le cas.

## Où travailler

Claude Code s'utilise dans un terminal ou dans l'application de bureau. La
version dans le navigateur ne convient pas : elle tourne sur un ordinateur
distant qui ne voit pas vos dossiers, et votre second cerveau vit chez vous.
L'application de bureau est en cours de vérification pour ce parcours.

## Ce que l'outil ne fait jamais

- Il n'envoie rien hors de votre ordinateur.
- Il n'installe rien sans votre accord explicite, outil par outil.
- Il ne lit pas votre messagerie sans votre accord, tracé, et jamais le corps
  des messages.
- Il ne copie pas vos documents : il pointe vers eux. Seule exception, les
  quelques documents structurants validés un par un à l'étape 5, quand vous
  n'avez aucune base de projets.
- Il n'écrit jamais dans vos dossiers de travail : seulement dans le second
  cerveau.
- Il ne lance jamais une étape à votre place : la page propose, vous décidez.
- Il ne se met pas à jour tout seul.
