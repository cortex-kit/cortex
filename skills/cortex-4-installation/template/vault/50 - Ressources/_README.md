# 50 - Ressources — les ressources transverses

Ce qui ne se rattache à aucun projet unique mais sert plusieurs domaines : références, tables de correspondance, notes de méthode transverses.

`Sources externes/` porte l'ingest : voir son propre `_README` et [[Ingest - Sources externes]].

Test d'appartenance : si la ressource ne sert qu'à un projet, elle vit dans ce projet. Un dossier « ressources » qui accueille tout ce qui n'a pas trouvé sa place devient l'endroit où l'on ne cherche jamais.
