# 40 - Acteurs — les entités

Une note par **entité** : société, organisation, service, institution. Créée depuis `_Template Acteur`.

## Pas de personnes physiques

Décision structurante, et elle a deux motifs.

Le premier est doctrinal : les coordonnées d'une personne changent, et leur canon est l'outil qui les gère — annuaire, CRM, messagerie. Une fiche de vault en devient une copie périmée, qu'on croira parce qu'elle est là.

Le second est réglementaire : un vault synchronisé, sauvegardé et lisible par un agent qui accumule des fiches nominatives devient un traitement de données personnelles, avec les obligations qui vont avec. Le vault n'a rien à y gagner.

Une personne se mentionne dans le corps d'une note et se rattache à son entité. Elle n'a pas de fiche.

## Ce dossier n'est pas un annuaire

Il porte les entités **avec lesquelles il se passe quelque chose** : celles qui apparaissent dans un projet, une décision, un journal. Une entité sans aucun lien entrant n'a rien à faire ici — c'est une ligne de prospection, pas un nœud de mémoire.

Le panneau **Liens entrants** d'une fiche d'acteur répond déjà à « quels projets la concernent ». Ne rien construire au-dessus.
